## 成果

LuminaMind 进入 **2026 金鸡湖创新创业大赛 OPC 专场赛复赛**，并获思必驰「智会未来」OPC 创新大赛 **优秀项目奖**。

## 项目思路

让智能助手的长期记忆 **可见、可编辑、可迁移**：使用 Markdown 原子笔记保存记忆，结合双链与语义检索，候选记忆由用户审查。

## 我的贡献

作为项目主导者之一，参与 **需求梳理、产品呈现、演示设计与路演答辩**。桌面端采用 Electron、React 与 TypeScript，服务端采用 Python 与 FastAPI。

项目仍在推进，代码和最新进展见公开仓库。
