## Problem

日常工作中，常用的小工具容易分散在多个窗口里。

## My Role

开发并维护这个公开的 Windows 桌面宠物项目。

## Approach

围绕系统托盘和桌面常驻体验，组合番茄钟、设备状态查看与快捷工具。

## Technical Highlights

- 使用 C# 构建 Windows 桌面应用。
- 把轻量陪伴感和实用入口放在同一个交互里。

## Results & Outputs

项目代码与当前功能见 GitHub 仓库。

## What I Learned

小工具是否好用，往往取决于它能否自然地融入每天的工作节奏。
