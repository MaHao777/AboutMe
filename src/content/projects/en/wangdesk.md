## Results

Develop and maintain **WangDesk, an open-source Windows desktop utility** combining a desktop pet, Pomodoro timer, device status, and shortcuts.

## Design & implementation

Built with **C#**, centered on the system tray and a persistent desktop presence to bring everyday tools into one place.

The project continues to evolve. Current features and code are in the public repository.
