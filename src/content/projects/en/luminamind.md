## Results

LuminaMind reached the **2026 Jinji Lake Innovation and Entrepreneurship Competition OPC semifinals** and received the **Outstanding Project Award** in AISpeech’s OPC Innovation Competition.

## Project idea

Make an agent’s long-term memory **visible, editable, and portable**. Memory lives in Markdown atomic notes, connected through backlinks and semantic retrieval. Users review proposed memories.

## My contribution

As one of the project leads, I helped with **requirements, product presentation, demo design, and pitch defense**. The desktop stack uses Electron, React, and TypeScript; the service uses Python and FastAPI.

Development continues. Code and current progress are available in the public repository.
