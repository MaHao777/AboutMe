# COSMOS · 第一阶段交互 Demo

开发分支：`codex/cosmos-core-demo`。入口为 `/cosmos/`，复用现有 Astro、TypeScript 和 Three.js；没有新增依赖、替换主页或部署。

## 本地启动

```powershell
cd D:\VS_project\MyWeb
npm install # 已有 node_modules 时可以跳过
npm run dev -- --host 127.0.0.1 --port 4321
```

打开 `http://127.0.0.1:4321/cosmos/`。原网站仍在 `/`。

如 Astro 提示本工程已有开发服务，直接使用它；若该服务的 Vite 依赖缓存已失效，可退出旧进程后重新启动，或显式使用 `npm run dev -- --force --host 127.0.0.1 --port 4321`。

查看构建产物：

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4323
```

打开 `http://127.0.0.1:4323/cosmos/`。

## 操作

- 滚轮向下前进、向上后退；停止输入后平滑减速。起点限制为 0。
- 按住 ↓ / Page Down 前进，↑ / Page Up 后退；空格立即停止。这是桌面键盘补充入口。
- 星球实体或名称标签可点击，悬停时高亮并改变指针。可通过 Tab 聚焦当前可见的名称标签，按 Enter 探索。
- 点击行星后冻结飞船位置，镜头平滑聚焦整个星系，右侧直接展示当前卫星的项目信息。
- 在场景或右侧内容区滚动滚轮，整组卫星正向 / 反向公转，文字同步上下移动。停止输入时，两者立即保持当前位置，可停在任何中间进度；没有惯性续转、自动吸附或独立播放的翻页动画。
- 卫星实际经过面向镜头的最前方位置时，才提交当前项目、标题计数与导航选中状态；接近该位置不会提前提交。多颗卫星与文字可循环探索，只有一颗卫星时仍可控制其公转，信息保持不变。
- 点击卫星实体、可见标签或面板里的项目名称，会平滑把相应卫星转到镜头前方。← / → 也可切换卫星。滚轮随时可以打断这类明确触发的对齐，并停在新的中间位置。所有入口使用同一公转状态，飞船始终保持暂停。
- 信息层背景采用加宽过渡区的分层玻璃效果，从左侧逐渐增强磨砂，再向右恢复清晰，正文保持锐利。文字位置由连续公转进度直接驱动，区域上下渐隐；系统选择减少动态效果时仅在实际到达项目位置后更新内容。
- Esc 或面板 ✕ 返回，经过 0.85 秒镜头归位后重新接受航行输入。
- 到达终点，先淡出，再统一重置航行、速度与摄像机，然后淡入。过渡期间丢弃输入。
- 已移除底部控制台、航标进度、左上介绍、右上坐标文字、面板底部提示与全局底部提示；选中卫星使用前景位置和基础高亮表示，没有直角框标记。

## 配置扩展

在 `universeData.ts` 增加 `PlanetData` 即可自动生成星球、标签、卫星和详情，不需修改航行逻辑。

位置使用 `[x, y, z]`：航行方向为 `-Z`，左右使用正负 X，依次增大负 Z 深度。卫星局部位置由轨道半径与相位计算，其数据嵌在父星球内部，`id` 应唯一。星球与卫星均应避开中心 `x = ±3.3` 的航道，并留出飞船及环形物的空间。

当前航道长 328，五颗星球分别位于 Z = −40、−94、−148、−202、−256，高度 Y = 4、−6、10、−9、7，形成左右与上下错位；黑洞在 −350。扩展更远航道时同步调整 `ROUTE_LENGTH`、`BLACK_HOLE_Z`，以及必要的镜头远裁剪和星点覆盖范围。

卫星使用半径恒定的圆轨道，每个星系通过 `orbitOrientation: { tilt, roll }` 配置绕 X 轴的倾角与绕 Z 轴的朝向，单位为弧度。目前五个星系分别呈水平、斜向和较正面的不同轨道姿态。同一星系内的卫星与轨道线共用同一刚性旋转。选择位置根据聚焦镜头方向求出轨道上朝向镜头的最前方点，窗口变化时保留连续进度。实际轨道半径至少为主星完整视觉外缘（含星环）加卫星半径，再加 0.75 的安全间距。扩大星球或轨道后，应运行全圈几何测试，确认仍避开中央航道。

状态流转：`flight → exploring → returning → flight`；循环为 `flight → departing → arriving → flight`。浏览器滚动位置不参与状态，因此复位不需要修正页面 scrollTop。

## 本阶段的简化与后续工作

飞船、球体与黑洞均为基础几何体；黑洞是视觉淡出复位，没有物理吸引或引力透镜。卫星在航行时低速公转，探索时由滚轮控制；整组共用角度偏移，保持安全距离。探索镜头按星系完整范围和右侧面板宽度构图，飞船在探索画面中隐藏，退出后恢复。内容仅使用少量现有公开项目摘要与明确标注的占位说明，没有扩充正式简历。

下一阶段建议先由本人实测鼠标与触控板手感，再调整航道长度、速度、星球间距和聚焦构图；随后完善真实内容、标签防重叠、移动端手势、低性能设备分级、模型与材质。此 Demo 未承诺完整移动端沉浸体验，未制作音效、自由飞行、碰撞或后端。
