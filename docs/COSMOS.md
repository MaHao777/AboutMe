# COSMOS 架构与验收

当前主站为五颗星球、17 颗卫星的宇宙个人网站。`/` 与 `/cosmos/` 共用 `CosmosPage.astro`，`/about/` 使用同一份 `UniverseContent.astro` 输出可直接阅读的详情。

## 内容与状态

一级简介在 `data/portfolio.ts`，空间关系在 `universeData.ts`。卫星依序为 4 / 3 / 3 / 3 / 4，每个 id 对应一个同名 `data-content-detail`。科研正文继续采用已发布的三个 Markdown 条目；其余内容不依赖已退役的旧主页资料对象。

`FlightController` 管理 flight → exploring → returning → flight 与黑洞淡出复位。`SatelliteOrbitController` 使用同一角度驱动卫星和简介：滚轮输入以 120 ms 平滑跟随，静止 200 ms 后，用 320 ms 缓入缓出吸附到最近卫星；未过半归回原位，过半转到下一锚点，恰好一半沿最后输入方向选择。经过或实际到达镜头前方锚点才提交选中项。滚轮可立即打断吸附及点击/左右键对齐，反转会丢弃旧方向余量；窗口变化保持完整进度。打开详情会取消所有待执行运动，关闭详情不会恢复旧吸附。

`PlanetInfoPanel` 只克隆正在阅读的模板；新详情从顶部开始。二级正文单击返回一级，点击内容面板左侧的场景从任一级直接回飞船视角，右上角叉叉仍直接回主轨道，Esc 保留逐级返回。场景记录 pointerdown 时是否已在探索、是否打开详情及是否位于面板左侧，避免打开内容的同一事件冒泡后立即关闭；只有按下和点击都位于左侧的简单点击才触发新增退出。一级页的卫星选择、链接、图片、按钮、文本选择、拖动和滚动保留原有作用。

触屏在场景和简介内上滑前进、下滑后退，使用同一 wheel 状态入口；详情内保留原生滚动。发生拖动后拦截对应点击，防止误开详情。低性能设备或浏览器不支持 WebGL 时可使用阅读版。

航行时只显示主星的简洁名称，17 颗卫星标签全部隐藏。鼠标悬浮主星或键盘聚焦其名称后，标签展开为边缘羽化的磨砂玻璃简介，展示该星球简介、内容摘要和进入提示；移开后收起简介。玻璃背景放在独立的蒙版伪元素上，四周渐隐，无可见框线和矩形阴影；文字分开淡入淡出，保持清晰。球面与卡片之间有可取消的 130 ms 悬浮退出缓冲，进入探索、打开详情和退出页面会立即清理。探索时只显示当前系统到达前方或悬浮的卫星标签。标签通过 `data-visible` 和 CSS visibility/opacity 分别控制可见性与动画，不用 `display:none` 打断淡出；不可见标签立即变为 inert、移出键盘顺序。玻璃层的淡入淡出独立于跟随星球的 3D 定位，展开过程中按实际高度避让页眉，减少动画跳动。减少动态效果时取消 CSS 过渡。

`PlanetSystem` 将主星自转与卫星自动公转分开：一级简介和二级详情中，主星仍以 .055 rad/s 缓慢自转，卫星自动轨道保持暂停，滚轮和方向键手动切换照常工作。系统减少动态效果时仍停止自转。浏览器实测两级页面中的主星角度持续增长，而未操作时的卫星轨道角度保持不变。

页头统一使用 `BlackHoleMark.astro` 的小黑洞 SVG 与 COSMOS 字样，去掉中文品牌后缀和分隔线；阅读版复用同一图标。标签验收覆盖鼠标球面/卡片之间移动、离开收起、键盘展开、航行隐藏卫星、探索和退出；390 × 844 下简介卡片未越界，无水平溢出。浏览器无脚本或 shader 错误，类型检查与构建成功，37 项现有测试通过。

## 空间与模块

航道方向为 -Z，长 328；五颗主星的 Z 为 -40 / -94 / -148 / -202 / -256，黑洞为 -350。主星有不同的倾斜轨道平面。全圈测试保证卫星不会碰撞主星/星环、其他卫星或进入中心航道。

| UniverseScene | 渲染、拾取、标签、输入与释放资源 |

## 核验范围

先运行 `node --test scripts/cosmos-*.test.mjs`，再运行 `npm run lint`、`npm run check` 与 `npm run build`。当前共有 37 项自动测试，其中 28 项覆盖航行/轨道，包括连续输入、最近锚点吸附、正反循环、打断与详情冻结，其余覆盖吸积盘和粒子时间轴。实际浏览器检查包括全部 17 组详情、分级返回、窄屏、触屏、复制微信号、阅读版及无 WebGL 回退。浏览器记录与截图保存在被 Git 忽略的 `output/playwright/` 或任务可视化目录。

证书副本只将覆盖敏感字段后的文档渲染为 PNG，原始成绩 PDF 不放进 public。构建应仅输出主页、兼容入口和阅读版；检查相对图片及站内链接均存在，检查 retired routes / 原始证件文件不在 dist。

模型使用程序化材质与几何，不依赖外部模型或贴图；没有音效、自由飞行或后端。Three.js 依赖仍会触发超过 500 kB 的构建块提示。缺少的个人素材与补充资料清单见 README。

2026-10-28 验收：23 项控制器/轨道测试通过；Astro 检查 0 errors / 0 warnings / 0 hints；三个静态页面构建成功。实际 Chromium 沿航道依次打开五颗星球和全部 17 个卫星详情，每个详情的飞船位置与轨道角度保持冻结，Esc 分级返回正常，微信号复制内容正确，全部本地证据图加载成功；正常流程脚本错误为 0。390 × 844 下复核简介与详情，无水平溢出；原生触摸事件确认拖动可驱动公转和航行且不会误开详情。无 JavaScript 的阅读版保留全部 17 组内容，无 WebGL 时提供阅读版入口。

## 3D 美术与材质

五颗主星分别采用琥珀经纬仪、蓝色光学干涉、紫色工程装甲、绿色海陆云层、玫瑰金通信网络。`planetMaterials.ts` 生成程序化表面、Fresnel 大气与细密星环；球体表面平滑，不再使用低多边形和线框光晕。17 颗卫星由 `Satellite.ts` 按内容 id 选择独立配色与纹理，例如奖章、芯片、雷达、黑胶纹路、篮球缝线和消息气泡。所有模型仍遵守既有几何安全边界。

飞船为珠白/钛合金双引擎探测器：连续曲面机身、深色座舱、倒角掠翼、分层喷口、航行灯与柔和等离子尾迹；尾迹随速度变化，减少动态效果时保持稳定。全局使用 ACES 色调映射、暖色主光与冷色轮廓光。

黑洞维持事件视界尺度 22，吸积盘外半径由 93 增至 112。`BlackHole.ts` 使用带上下表面及内外侧壁的闭合环形盘体，保留约三成纵向投影，并横向倾斜约 7.4°。`accretionProfile.ts` 定义真实半厚度：外缘约 .055，内缘约 3.955，形成外薄内厚的连续隆起。盘面的径向能量从外到内依次经过 `0,1,0,4,1,5,2,7,2,9`，节点间使用平滑插值，再采样为本地 GPU 查找纹理；亮度有明确峰谷，不采用均匀增亮。内侧偏暖白，外侧偏铜色，保留左右亮度差和柔和外边界。光流角速度系数从 .62 降至 .16，仍保持内圈较快、外圈较慢。

上拱和下弧通过三次曲线肩部融入盘面：连接圆弧时匹配位置与切线，连接盘面时切线渐平，并与盘体使用相同的横向倾角；不再使用上下 Y 区域的硬截断。近半面有真实厚度，远半面由暗核遮挡，查找纹理随材质生命周期释放。独立绕行光丝保持移除；远景使用屏幕导数过滤过细光纹。进入探索时背景黑洞亮度平滑降至 22%，返回航行恢复；减少动态效果时停止光流并直接切换亮度。该效果为美术化实时视觉，没有求解广义相对论。

光学层开启负向 polygon offset，使亮环在深度缓冲中稳定处于暗核前方；单靠世界坐标 .02 的间隔，在远景会小于 24 位深度缓冲的一个精度格，导致移动时频闪。保留深度测试以维持前景遮挡。固定流体时间、仅移动镜头的 128 帧 GPU 回归中，微移组亮环亮度变异系数从 .3709 降至 .0037，常规移动组从 .4181 降至 .0082；随后完成完整场景前后航行验收。一次性测试页与逐帧结果保存在本任务 `horizon-refinement` 目录，测试路由不进入正式构建。

粒子标题中文使用得意黑 Smiley Sans，英文 `NEVER STOP` 使用 Orbitron 800 字重与独立字距；字体和 OFL 许可均存放于 `public/fonts/`。字体异步加载后重采样两套字形，保持正在运行的两分钟切换进度；字体加载失败保留本地字体回退，场景释放后不再更新字形。

## 粒子主题与穿越

已删除两侧航道线及中心地面标记。主星表面不再因悬停提亮或染色；大气层使用两边渐隐的柔光，悬停只平滑增加边缘亮度。卫星球体与柔光壳均位于原半径范围内，不扩大几何安全边界。

`ParticleMotto` 用 Canvas2D 采样字形，生成 6200 颗真正的 Three.js 点粒子，不渲染文字贴图。文字位于黑洞后上方，按活动场景时间每 120 秒在“无限进步”和“NEVER STOP”之间切换，3.2 秒内散开、旋转并重新成字。该时间轴使用未截断的帧间时间，不因低帧率拖慢两分钟周期；页面隐藏时停止渲染。减少动态效果时在相同时点直接换字。使用前述随站点分发的得意黑与 Orbitron 字体，失败时回退到本机字体。

文字成形后仍有轻微呼吸、逐粒波动和横向流光，约 14% 粒子会轮流短暂游离并回归字形，保持主体可读。语言重组时常驻动作逐渐减弱，减少动态效果时关闭这些运动。英文采用全大写 `NEVER STOP`。`motto-idle-audit.json` 与 `motto-idle-*.png` 验证了成字后的实际画面变化、大写英文、两分钟重组与减少动态效果，未发现脚本或 GLSL 错误。

黑洞光流由前述环形盘体与透镜弧的材质生成，独立绕行拖尾已经移除。保留参考图的暖白轮廓、倾斜吸积盘与探索调暗，减少动态效果时冻结材质时间。

`FlightController.transitProgress` 是穿越唯一进度来源。离开阶段 2.1 秒，进入阶段 1.9 秒；仅在中点完全遮挡时归零位置、速度与输入。相机先朝暗核俯冲、扩大视角并轻微倾斜，飞船随之远去；`WarpTransit` 展开蓝金色星流隧道，最后从中心打开出口，飞船和页面逐渐恢复。此期间拒绝航行和星球输入，不显示加载文案或转圈。减少动态效果时保留柔和暗场过渡，不使用缩放、旋转或高速星流。

本轮 34 项控制器/主题时间测试全部通过，类型检查与构建成功。`immersive-horizon-audit.json` / `immersive-*.png` 验证中英文两个方向重组、阅读冻结、入洞/隧道/出洞、复位后继续航行和窄屏，脚本及 GLSL 错误为 0；`detail-exit-review.json` 的 14 项桌面/触屏回归亦通过。测试时间跳转只存在于忽略的浏览器脚本，不提供生产页面快捷入口。
