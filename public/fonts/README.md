# Local particle display fonts

- `SmileySans-Oblique.ttf.woff2`: unmodified Smiley Sans v2.0.1 release from https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1; license in `SmileySans-LICENSE.txt`.
- `Orbitron-Variable.ttf`: unmodified variable font from https://github.com/google/fonts/tree/main/ofl/orbitron; license in `Orbitron-OFL.txt`.

Both are served locally and sampled into the two particle mottos by Canvas2D. No external font service is contacted by the website.
